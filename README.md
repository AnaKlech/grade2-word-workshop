# Second Grade Word Workshop

Seven grammar lessons for a second grader, split into three ~25-minute sittings.

| Sitting | Lessons |
| --- | --- |
| 1. Words that change | Irregular plurals · Past tense verbs |
| 2. Describing & building words | Adjectives · Adverbs · Compound words |
| 3. Letters & review | Letter greeting comma · Big review |

Each lesson gives the rule, a "write this down" task for paper, and self-checking
questions covering every word taught. 85 questions in total.

**Read aloud.** Every rule, question, example and word list has a speaker button
that reads it out, for readers who are not yet fluent. Uses the browser's own
speech engine — no account, no API key, no network call.

**Built to survive old school computers.** All questions are plain HTML, so they
appear even if JavaScript is blocked or broken; the script is ES5 only.

Single self-contained `index.html` — no build step.
